# ব্লগ

1. **Add file → Create new file** চাপুন।
2. ফাইলের নাম দিন এভাবে: `2026-11-09 লেখার শিরোনাম.txt` (আগে তারিখ, তারপর শিরোনাম, শেষে `.txt`)।
3. নিচের বাক্সে লেখা পেস্ট করুন। অনুচ্ছেদের মাঝে একটা ফাঁকা লাইন রাখুন।
4. **Commit changes** চাপুন।

নতুন লেখা সবার উপরে দেখাবে। লেখা বদলাতে ফাইলটা খুলে পেনসিল আইকনে চাপুন।
