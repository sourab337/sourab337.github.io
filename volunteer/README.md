# ভলান্টিয়ার ছবি

1. প্রতিটা কাজের জন্য একটা ফোল্ডার বানান। ফোল্ডারের নামই সাইটে কাজের নাম হিসেবে দেখাবে।
2. ছবির ফোল্ডারটা **Add file → Upload files** পেজে টেনে এনে ছাড়ুন, তারপর **Commit changes** চাপুন।
3. ফাইলের নামই ক্যাপশন হবে, যেমন `Education camp 2024.jpg`। `IMG_1234.jpg` ধরনের নামে ক্যাপশন দেখাবে না।
4. কাজের বিবরণ দিতে চাইলে ওই ফোল্ডারে `about.txt` নামে একটা ফাইল রাখুন।

ছবি JPG, PNG, WEBP বা GIF হতে পারে। প্রতিটা ১ MB-র নিচে রাখা ভালো।
